# Design Rules — RORAX App Store

> Read this file before any UI/UX work in this repo.
> Generated by the `ui-android` skill. Updated: 2026-11-26.

## Stack

- Jetpack Compose (BOM 2024.09.00) + Material 3
- Kotlin 2.2.10, AGP 9.1.1
- minSdk 24, targetSdk 36
- Mode: extend (theme existed; tokens completed and documented here)

Documented exceptions to the skill target: minSdk is 24 because the app must work on all devices, and the Compose BOM is 2024.09.00. All UI code avoids APIs unavailable on minSdk 24 without a guard.

## Aesthetic anchor

- **Primary:** Material You (Android Expressive), fixed seed `#00E5A8`, tonal-spot variant, contrast level 0.
- **Type:** Rajdhani, declared once in `Type.kt`, mapped to seven Material 3 sizes.
- **Motion:** Material You emphasized easing, 100/200/300/450ms durations from `Motion.kt`.

Every value in the theme files traces to the Material You anchor recipe. The seed and generated roles were produced with `@material/material-color-utilities` 0.3.0.

## Active ban patterns

- Generic gradient slop
- Lorem ipsum and filler copy
- Arbitrary `dp` / `sp` / `Color` values

Opt-in bans are off. The existing app uses static skeleton blocks with no looping shimmer, no card stacking, no auto-playing carousels, and no decorative blur.

No raw dimensions or colors in composables. Use `MaterialTheme.spacing`, `MaterialTheme.dimensions`, `MaterialTheme.shapes`, `MaterialTheme.colorScheme`, and `MaterialTheme.typography`.

## Project-wide component choices

- Card variant: **Surface with outline border** (one level only; no elevation mixed with borders).
- Button variants: **Button** (primary install/update), **OutlinedButton** (open), **TextButton** (low-emphasis text actions).
- TextField: **OutlinedTextField**.
- Press feedback: **built-in Material ripple**.
- Density: **balanced**.
- Dark theme: **required**, with light-theme parity.
- Dynamic wallpaper color: **off** (fixed brand seed).
- Icon family: **Rounded** (`Icons.Rounded.*` and `Icons.AutoMirrored.Rounded.*`). No other family is mixed in.
- Snackbar action case: sentence case.
- Navigation: `NavigationBar` with three destinations; labels always shown.

## Copy

Sentence case on all user-facing labels. No placeholder or marketing filler. Strings live in `app/src/main/res/values/strings.xml`.

## Verification

Before claiming any UI work done, run:

```bash
./gradlew detektDesign lintDebug
```

`detektDesign` is a custom Gradle verification task (no detekt plugin is installed). It scans non-theme Kotlin files for raw `dp`/`sp`/`Color(0x...)` literals, banned gradients, filler copy, buzzwords, inline font declarations, and decorative infinite transitions.

## Adding new tokens

If a value is missing from the theme files, extend the theme file and document it here. Never add an arbitrary value inline in a composable.
